# 電影夥伴 Bot 03 隱私說明

本專案提供電影查詢、附近影院與使用者確認後的個人票根收藏。這是可自行執行的開源學習專案；部署者負責保管本機資料並提供聯絡方式。

## 位置與對話

- 提供地址、地標或傳送 LINE 位置時，查詢所需資訊會送至 Google Maps Platform，以找出位置與附近影院。
- LINE 的經緯度由程式傳給地圖服務，不加入 Gemini 的文字提示或工具結果；模型會看到查詢問題、影院地址、來源連結與距離。文字輸入的地址／地標會和一般訊息一起交由 Gemini 處理。
- LINE 定位的座標在對話記憶體最多保留 15 分鐘；到期會清除該對話，停止使用服務或重新啟動也會清除。輸入「清除位置」可立即清除目前對話與定位，已儲存票根另行保留。
- LINE webhook 待處理事件會暫存在本機 SQLite，包含事件 ID、使用者 ID、reply token 與座標；完成、失敗或事件過期後清空內容，只保留去重 ID、狀態與時間。服務停止期間尚未處理的事件會留待下次啟動清除。需清除磁碟備份或 SQLite 歷史頁面的使用者，應由部署者另行管理保存期限。
- Google Maps 查詢結果不由本程式建立持久快取；必要的結果會留在 ADK 記憶體對話供後續問答使用。未含 LINE 定位的對話最多 20 回合，閒置超過 30 分鐘後於後續處理時清除。

## 票根

票根由你提供資料並按確認後儲存於部署者的 SQLite。LINE 原始經緯度不加入票根；你自行在文字訊息輸入的地址可能成為原始訊息的一部分，並隨票根草稿確認保存。模型不能直接替你確認。各使用者只能經 Bot 查自己的票根。
